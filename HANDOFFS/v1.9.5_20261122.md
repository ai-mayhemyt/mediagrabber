## Shipped in v1.9.5
1. **Mobile UI:** Responsive layout fixed for iPhone (Portrait). Logo is at the top, nav buttons scroll horizontally, Paste box is full-width, and action buttons wrap cleanly.
2. **Version Manager:** Moved into the `features.js` Server Manager modal under the "Versions" tab. Added "Check for Update" button that uses local `git ls-remote --tags origin` to compare the current running version against GitHub.
3. **Scheduled Downloads:**
   - SQLite `scheduled_jobs` table added to `users.db`.
   - Background daemon thread (`_scheduler_loop`) wakes every 30s, checks for due jobs, and fires `grab()`.
   - New "📅 Schedule" modal in `features.js` allows queueing URLs and selecting a date/time.
   - Pending jobs are listed in the modal with a "Delete" button.

## Known Quirks
- **`grab()` refactor:** `grab()` now accepts `form_data=None`. If `None`, it defaults to `request.form`. This allows the scheduler thread to call it directly with a dict.
- **Scheduler thread:** Guarded by `os.environ["_MG_SCHEDULER_STARTED"]` to prevent double-starts under Flask debug mode.
- **UI Logic:** Almost all the dynamic UI (Server Manager, Versions, Schedule modal) lives in `web/static/features.js`, NOT in the inline HTML of `app.py`.

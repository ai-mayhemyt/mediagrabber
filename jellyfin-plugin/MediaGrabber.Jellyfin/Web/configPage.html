MediaGrabber — Jellyfin Edition

Download YouTube, YouTube Music, Spotify, Instagram, and TikTok media straight into your MediaGrabber libraries without leaving Jellyfin. Supports single URLs, bulk playlists, audio/video modes, and live queue tracking.

Required: Generate a MediaGrabber API key with download or admin scope in MediaGrabber → Account → API Tokens.
Jellyfin Plugin Repository URL: https://github.com/ai-mayhemyt/MediaGrabber-Jellyfin-Edition/releases/latest/download/manifest.json
Full URL reachable from your Jellyfin server (e.g. http://127.0.0.1:3000 or http://192.168.1.50:3000).
Required for downloading, queue status, cancel, and retry actions. Generate one in MediaGrabber under Account → API Tokens.
